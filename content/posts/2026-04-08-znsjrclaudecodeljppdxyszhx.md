## 一、为什么我一开始觉得“让AI懂品牌调性”是玄学？  

第一次给 Claude Code 喂品牌资料时，我信心满满——20页PDF，含VI手册、SOP文案范例、三年社媒热帖合集，连字体字号都标了色值。结果它交来一篇618电商主图文案，开头就是：  
> “以用户为中心，深度耦合消费场景，构建可持续增长飞轮，实现价值闭环与体验升维……”  

客户微信秒回一张截图，配文：“这是在写互联网黑话词典？还是我们家卖的是‘赋能型睫毛膏’？”  

![失败文案对比截图：左侧是AI生成的黑话堆砌段落，右侧是客户手写批注“请停止抽象化表达”](https://dashscope-result-sh.oss-cn-shanghai.aliyuncs.com/7d/9d/20260408/d23adf3d/48e2fad0-a0f3-96ab-bb8c-52dfcbc3d6d62878075418.png?Expires=1776232457&OSSAccessKeyId=LTAI5tKPD3TMqf2Lna1fASuh&Signature=4g5yi0fkjCNO5glO6EvNPdLlic0%3D)  

那一刻我盯着屏幕，手心发潮。不是模型不行——它刚用同一套资料，精准复现了某竞品小红书评论区的emoji节奏和分段呼吸感；而是我犯了个致命错误：**把“品牌调性”当成了可打包上传的静态知识库，而不是需要被翻译成模型能感知的“语言指纹”**。  

调性不是文档里的形容词（“年轻”“专业”“松弛”），而是动词：它怎么断句？爱用什么语气词？拒绝哪类修辞？在什么语境下会突然变短？  

我翻出那20页手册里唯一被划了三道横线的一页——创始人手写的会议纪要：“别写‘尊享’，写‘喏，给你留了最后一盒’；别提‘科技成分’，说‘这玩意儿我试了17次才敢给你’。”  

原来，“调性”藏在人话的褶皱里，不在PPT的标题栏里。  

多数人卡在第一步，不是因为不会写Prompt，而是没意识到：**“请写出有松弛感的文案” ≈ “请凭空召唤空气”，而“每句≤12字，句尾带‘哎’‘哈’‘喏’，禁用‘之’‘其’‘乃’”才是指令**。

## 二、我的三步实操法：从“说不清”到“喂得准”  

### 第一步：把调性翻译成“人话特征清单”  

某新消费茶饮品牌要求“松弛感”。市场总监口头强调三次，但文案组始终写不出味道。我拉来他们最火的3条小红书笔记，逐字拆解：  

| 特征维度 | 具体表现 | 反例（自动过滤） |
|----------|----------|------------------|
| **句长** | 平均9.2字/句，最长11字（如：“冰块咔嚓，一口透心凉”） | >14字（如：“这款冷泡茶采用高山云雾嫩芽经低温慢萃工艺制成”） |
| **叹词** | 每150字必出现1次“哎”“哈”“喏”“呀”（口语锚点） | 零叹词，或滥用“哦～”“呢～”（显幼稚） |
| **修辞** | 拒绝成语/四字词；用生活化比喻（“像偷喝老爸冰箱里的汽水”） | “沁人心脾”“回味悠长”“匠心独运” |

→ 直接塞进Prompt：  
```prompt
你是一名资深新消费文案，为「山野茶事」品牌服务。请严格遵守以下3条铁律：  
1. 每句≤12字，禁止换行句超过2行；  
2. 每段必含1个口语叹词（仅限：哎/哈/喏/呀/嚯）；  
3. 禁用任何成语、四字词、文言虚词（之/其/乃/遂）。  
现在为新品「青梅气泡茶」写3条小红书标题（带emoji）：  
```

### 第二步：用“正反例对撞法”训练模型  

只给正面案例？等于放AI去自由发挥。我吃过亏——喂了10条“松弛感”范例，它产出一句：“尊享青梅暴击体验！💥”，还自信加了emoji。  

**关键动作：每1条正例，必须配1条错例+批注**。例如：  
> ✅ 正例：“喏，青梅味儿刚上头，气泡就来捣乱～”  
> ❌ 错例：“尊享青梅暴击体验！💥” → 批注：违反“去高端化”原则，“尊享”制造距离感，“暴击”过度用力，丢失松弛呼吸感  

Claude Code 对批注极其敏感。当我把这类“错例+原因”批量喂入，它的错误率从37%降到6%。  

### 第三步：绑定受众画像做动态校验  

“针对年轻人”？太宽泛。我们给Claude Code加了个“受众触发器”：  

```prompt
当文案中出现以下任一关键词时，自动切换模式：  
- 出现「早八人」「通勤」「地铁」→ 启用「咖啡渍emoji☕+碎片短句」模式（例：“闹钟响了☕ 嘴里还有青梅味儿”）  
- 出现「加班」「方案」「PPT」→ 加入自嘲梗（例：“改第8版PPT时，这杯茶救了我命”）  
- 出现「闺蜜」「拍照」「打卡」→ 插入视觉提示（例：“瓶身绿得像你手机相册里那张莫奈”）  
```

## 三、那些让我连夜改prompt的“隐形雷区”  

### 雷区1：调性关键词自相矛盾  
**案例**：医疗健康品牌要求“专业但亲切”。Claude Code把“本品获FDA认证”写成：“这个小糖丸超靠谱哦～✨”。市场总监电话里吼：“FDA认证是能‘哦～’出来的吗？！”  

✅ **避坑口诀：专业信息不抢主语，括号备注是安全带**  
→ 改后Prompt：  
```prompt
主文案全程口语化（用“咱”“你”“哈”），所有专业信息强制放入括号：  
例：“喝完嘴不干（含玻尿酸钠，临床验证保湿力↑300%）”  
禁用“权威认证”“尖端科技”等抽象词，括号外不出现任何数据/机构名。  
```  

### 雷区2：忽略渠道特性导致调性错位  
**血泪教训**：把小红书爆款文案“救命！这睫毛膏焊在眼睛上！🌧️（下雨都不晕染）”直接复用到公众号推文，老板怒删：“品牌要稳重，不是要焊工执照！”  

✅ **避坑口诀：渠道即语境，Prompt开头必写渠道身份**  
→ 强制声明：  
```prompt
【你当前身份】：公众号主编（非小红书博主）。读者正在午休刷手机，耐心≤8秒。  
禁用感叹号密集阵、网络热梗、夸张动词（“焊”“炸”“杀疯了”）。  
用“静悄悄”“不声不响”“自己就稳住了”替代绝对化表述。  
```  

### 雷区3：受众画像太宽泛等于没画  
**原始画像**：“25-35岁女性，一线/新一线城市，关注护肤”。  
→ AI产出：“姐妹们快冲！这精华水让你白成一道光！”（完全没戳中任何人）  

✅ **避坑口诀：画像要具体到能叫出她地铁站名**  
→ 改进后：  
```prompt
目标用户：上海浦东新区·养猫·通勤地铁40分钟·小红书收藏夹有17个护肤合集·上周刚被老板push改方案3次的职场新人。  
她刷手机时单手操作，看到“玻尿酸”会翻白眼，看到“不用等吸收，挤完就去赶地铁”会停住。  
```

## 四、我们最终跑通的SOP：让Claude Code成为品牌“调性守门员”  

现在，我们团队的文案流程已固化为5步人机协作流水线：  

```
收到需求 → 拆解为3个特征词 → 调取历史正反例库 → 生成初稿 → 用预设校验清单过筛（含5个必检项） → 人工微调  
```  

**校验清单5必检项**（Claude Code自检+人工复核）：  
1. ✅ 句长是否超12字？（用`len()`函数粗筛）  
2. ✅ 是否缺失叹词？（grep “哎\|哈\|喏\|呀”）  
3. ✅ 括号外是否出现专业术语？（正则匹配：`(?<!\().*(FDA|临床|浓度|μg).*?(?!\))`）  
4. ✅ 渠道关键词是否触发对应模式？（if “早八人” in text → check ☕ emoji）  
5. ✅ 是否出现画像禁止词？（黑名单：“姐妹”“冲”“绝了”“yyds”）  

**工具包已开源**（团队内部）：  
- 📋 **《调性特征速查表》**：32个高频词直译（例：“高级感”≠“奢华”，而是“名词前置+弱动词+留白标点” → “羊绒。不扎。静音。”）  
- 🧩 **《受众画像快填模板》**：6个问题直击决策场景：  
  > ① 她最近一次焦虑是什么事？（例：改PPT到凌晨）  
  > ② 她手机相册最新3张截图是什么？（例：地铁拥挤照/猫吐毛球/咖啡渍键盘）  
  > ③ 她收藏夹里最多的3个话题？（例：通勤穿搭/猫粮测评/Excel技巧）  
  > ……（略）  

**效果验证**：上线3个月，市场部文案返工率↓67%，客户反馈原话：“终于不用反复说‘再年轻一点’了——你们的AI比我还懂我们品牌。”  

最后说句实在话：**我们不要全自动，只要确定性**。  
- ✅ **特征库维护**：由文案组长+设计主管双签，每月更新正反例  
- ✅ **终审权限**：市场总监保留最终否决权，但只审“是否越界”，不改字词  
- ✅ **Claude Code角色**：不是写手，是“调性守门员”——它不创造风格，只严防死守风格不漂移  

毕竟，品牌调性不是AI该发明的东西，而是人类用20年时间刻进消费者神经里的条件反射。我们的任务，只是帮AI听清那声细微却坚定的“咔哒”——锁扣闭合的声音。
